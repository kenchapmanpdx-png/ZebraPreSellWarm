- **`DATABASE_URL`** — must be set on Vercel for the API to actually persist submissions. See `DEPLOY.md`. Without it, submissions only land in Vercel function logs (still recoverable but not queryable).
- **Custom domain** — `index.html` canonical + OG URLs point at `zebra-pre-sell-warm.vercel.app`. If you switch to `zebrawell.com`, find/replace.
- **Drizzle schema push** — run `npm run db:push` once `DATABASE_URL` is set to create the four tables.
- **Six dead components** — `ClinicalRationale`, `DifferenceSection`, `WhyZebra`, `InteractiveIngredientMap`, `PreorderReservation`, `WhatYouGet`. Per your June 23 changelog these were added then apparently removed from pages. Decide: delete or reintroduce.
